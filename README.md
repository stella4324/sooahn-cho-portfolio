# Sooahn Cho — Portfolio

A responsive, three-page static website made with plain HTML, CSS, and JavaScript. The home page links to a CV and projects page and a personal photo journal. The personal page uses selected scenery photographs supplied by Sooahn; the CV page includes an interactive binary search over an alphabetically sorted list of interests.

## Publish with GitHub Pages

1. Create a **public** GitHub repository, for example `sooahn-cho-portfolio`.
2. Upload the **contents** of this folder to the repository root (the files `index.html`, `cv.html`, and `personal.html` should be visible at the top level). Keep the `photos` folder intact.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)` and save.
5. The site will be available at `https://YOUR-GITHUB-USERNAME.github.io/sooahn-cho-portfolio/` after GitHub Pages finishes publishing.
6. Replace the example URL on the first line of `submission.txt` with the published address before submitting.

## Pages

- `index.html`: landing page with clickable links to both sections.
- `cv.html`: education, interests, projects, skills, contact, and binary-search feature.
- `personal.html`: a compact photo journal using selected personal photographs.
- `photos/`: five scenery photographs used in the photo journal.
